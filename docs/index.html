GPW i Xetra: dane po zakończeniu sesji (EOD), nie bieżący kurs. Pozostałe rynki według opóźnienia pokazanego przez dostawcę. Widżet aktualizuje się przy otwartej stronie; nie jest usługą alertów.

Notowania: TradingView — dostępne rynki i rodzaje danych. Stała lista publiczna; portfel nie jest przekazywany dostawcy.

Monitoring mojego portfela

Import portfela nadal dopasowuje artykuły lokalnie. Automatyczny monitoring kursów i alerty portfela nie są aktywne: wymagają osobnego źródła danych z prawem do publikacji wspólnej bazy. Zgodnie z Twoim wyborem obecnie pokazujemy darmowy widżet rynku.

Od razu działa wyszukiwanie słów, odmian i pojęć pokrewnych. AI dodaje podobieństwo znaczeniowe.

AI pobiera model z Hugging Face (około 120 MB + pliki językowe), a następnie oblicza zapytania lokalnie. Model nie generuje odpowiedzi ani prognoz giełdowych. Dane portfela pozostają w przeglądarce.

Import portfela z konta maklerskiego

Plik CSV / TSV / XLSX odczytujemy tylko na Twoim urządzeniu. Do dopasowania zapisujemy lokalnie nazwy, tickery i ISIN — bez liczby akcji, salda, cen, wartości pozycji i numeru rachunku.

Importuj aktualne pozycje. Sprawdź nazwy przed zapisaniem; dla samego kodu wpisz nazwę firmy używaną w artykułach. Lista nie jest wysyłana na GitHub ani synchronizowana między urządzeniami.

Automatyzacja zbiera wspólne archiwum. „Mój portfel” wyszukuje w nim artykuły o Twoich spółkach; nie jest to osobny serwerowy monitoring rachunku.
